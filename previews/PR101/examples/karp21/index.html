Karp-21 Problem Library

QUBO.Karp21 provides ready-to-use, JuMP-native model builders for all 21 NP-complete problems from Richard M. Karp's 1972 paper "Reducibility Among Combinatorial Problems" (plus standard optimization variants such as independent_set, hamiltonian_path, travelling_salesman, and subset_sum).

Rather than hard-coding manual penalty coefficients, every builder returns a constrained JuMP.Model whose constraints are automatically compiled and penalized by ToQUBO.jl and whose post-solve constraint satisfaction can be audited with ToQUBO.feasibility_report(model).

Example: Maximum Clique & Feasibility Audit

edges = [(1, 2), (2, 3), (1, 3), (3, 4)]
model = Karp21.clique(
    4,
    edges;
    optimizer = () -> ToQUBO.Optimizer(ExactSampler.Optimizer),
)
optimize!(model)

rep = ToQUBO.feasibility_report(model)
(
    selected = round.(Int, value.(model[:x])),
    objective = objective_value(model),
    feasible = rep.results[1].feasible,
)
(selected = [1, 1, 1, 0], objective = 3.0, feasible = true)

API Reference

QUBO.Karp21.PROBLEMS — Constant
Karp21.PROBLEMS

Catalog of all 21 NP-complete problems from Karp (1972), "Reducibility Among Combinatorial Problems", mapped to their JuMP model builders in QUBO.Karp21.

source
QUBO.Karp21.satisfiability — Function
Karp21.satisfiability(num_variables, clauses; hard_clauses=true, optimizer=nothing)

Build a JuMP model for Karp #1 (Satisfiability / Max-SAT). Each clause in clauses is a vector of signed integer literals in ±(1:num_variables). When hard_clauses=true (default), every clause is registered as a hard constraint sum(lits) >= 1. When hard_clauses=false, auxiliary clause indicators y[c] are maximized (Max-SAT).

source
QUBO.Karp21.three_sat — Function
Karp21.three_sat(num_variables, clauses; hard_clauses=true, optimizer=nothing)

Build a JuMP model for Karp #11 (3-Satisfiability / 3-SAT). Validates that every clause has between 1 and 3 literals before delegating to satisfiability.

source
QUBO.Karp21.zero_one_integer_programming — Function
Karp21.zero_one_integer_programming(A, b; c=nothing, sense=:EqualTo, objective_sense=MOI.MIN_SENSE, optimizer=nothing)

Build a JuMP model for Karp #2 (0-1 Integer Programming). Registers linear constraints A * x == b (sense=:EqualTo), A * x <= b (sense=:LessThan), or A * x >= b (sense=:GreaterThan) over binary variables x[1:n].

source
QUBO.Karp21.clique — Function
Karp21.clique(num_vertices, edges; weights=nothing, target_size=nothing, optimizer=nothing)
Karp21.clique(adj_matrix; weights=nothing, target_size=nothing, optimizer=nothing)

Build a JuMP model for Karp #3 (Clique / Maximum Weight Clique). Registers non-edge exclusion constraints x[u] + x[v] <= 1 for every non-adjacent pair (u, v) and maximizes sum(weights[v] * x[v]).

source
QUBO.Karp21.independent_set — Function
Karp21.independent_set(num_vertices, edges; weights=nothing, optimizer=nothing)
Karp21.independent_set(adj_matrix; weights=nothing, optimizer=nothing)

Build a JuMP model for Maximum Independent Set (complement of clique). Registers edge conflict constraints x[u] + x[v] <= 1 for every (u, v) in edges.

source
QUBO.Karp21.set_packing — Function
Karp21.set_packing(universe, subsets; weights=nothing, optimizer=nothing)

Build a JuMP model for Karp #4 (Set Packing). Registers pairwise disjointness constraints x[i] + x[j] <= 1 for overlapping subsets and maximizes sum(weights[j] * x[j]).

source
QUBO.Karp21.vertex_cover — Function
Karp21.vertex_cover(num_vertices, edges; weights=nothing, optimizer=nothing)
Karp21.vertex_cover(adj_matrix; weights=nothing, optimizer=nothing)

Build a JuMP model for Karp #5 (Node Cover / Minimum Vertex Cover). Registers edge coverage constraints x[u] + x[v] >= 1 for every (u, v) in edges and minimizes sum(weights[v] * x[v]).

source
QUBO.Karp21.set_cover — Function
Karp21.set_cover(universe, subsets; weights=nothing, optimizer=nothing)

Build a JuMP model for Karp #6 (Set Covering). Registers element coverage constraints sum(x[j] for j with e in subsets[j]) >= 1 for each e in universe and minimizes sum(weights[j] * x[j]).

source
QUBO.Karp21.feedback_vertex_set — Function
Karp21.feedback_vertex_set(num_vertices, directed_edges; weights=nothing, optimizer=nothing)

Build a JuMP model for Karp #7 (Feedback Node Set / Directed Feedback Vertex Set). Uses binary removal variables x[v] and tournament ordering variables p[u, v] (u < v) with transitivity constraints so that remaining vertices admit a topological ordering.

source
QUBO.Karp21.feedback_arc_set — Function
Karp21.feedback_arc_set(num_vertices, directed_edges; weights=nothing, optimizer=nothing)

Build a JuMP model for Karp #8 (Feedback Arc Set / Directed Feedback Edge Set). Uses binary arc-removal variables y[e] for each edge e and tournament ordering variables p[u, v] (u < v) with transitivity constraints.

source
QUBO.Karp21.directed_hamiltonian_cycle — Function
Karp21.directed_hamiltonian_cycle(num_vertices, directed_edges; fix_start=true, optimizer=nothing)

Build a JuMP model for Karp #9 (Directed Hamilton Circuit). Uses binary position variables x[v, pos] with bijective assignment constraints and non-arc transition exclusions x[u, pos] + x[v, next_pos] <= 1.

QUBO.Karp21.travelling_salesman — Function
Karp21.travelling_salesman(distance_matrix; fix_start=true, optimizer=nothing)

Build a JuMP model for the Travelling Salesman Problem (TSP) with quadratic tour-length objective and bijective tour-position constraints.

source
QUBO.Karp21.graph_coloring — Function
Karp21.graph_coloring(num_vertices, edges, num_colors; minimize_colors=false, optimizer=nothing)
Karp21.graph_coloring(adj_matrix, num_colors; minimize_colors=false, optimizer=nothing)

Build a JuMP model for Karp #12 (Chromatic Number / Graph Coloring). Assigns each vertex v exactly one color c in 1:num_colors (sum(x[v, :]) == 1) and forbids adjacent vertices from sharing a color (x[u, c] + x[v, c] <= 1). When minimize_colors=true, introduces color-usage indicators u[c] and minimizes sum(u).

Karp21.chromatic_number(adj_matrix, max_colors; optimizer=nothing)

Build a JuMP model for Karp #12 (Chromatic Number) minimizing the number of used colors.

QUBO.Karp21.clique_cover — Function
Karp21.clique_cover(num_vertices, edges, num_cliques; minimize_cliques=false, optimizer=nothing)
Karp21.clique_cover(adj_matrix, num_cliques; minimize_cliques=false, optimizer=nothing)

Build a JuMP model for Karp #13 (Clique Cover), equivalent to coloring the complement graph.

source
QUBO.Karp21.exact_cover — Function
Karp21.exact_cover(universe, subsets; weights=nothing, optimizer=nothing)

Build a JuMP model for Karp #14 (Exact Cover). Registers exact partitioning constraints sum(x[j] for j with e in subsets[j]) == 1 for every e in universe.

source
QUBO.Karp21.hitting_set — Function
Karp21.hitting_set(universe, subsets; weights=nothing, optimizer=nothing)

Build a JuMP model for Karp #15 (Hitting Set). Selects elements x[i] from universe so every subset in subsets contains at least one selected element (sum(x[i] for u[i] in S_j) >= 1), minimizing sum(weights[i] * x[i]).

source
QUBO.Karp21.steiner_tree — Function
Karp21.steiner_tree(num_vertices, edges, terminals; weights=nothing, optimizer=nothing)

Build a JuMP model for Karp #16 (Steiner Tree). Selects vertex indicators x[v] (x[t] == 1 for t in terminals) and edge indicators y[e] (1:m) satisfying tree cardinality sum(y) == sum(x) - 1, endpoint inclusion y[e] <= x[u] and y[e] <= x[v], and terminal-cut connectivity constraints.

source
QUBO.Karp21.three_dimensional_matching — Function
Karp21.three_dimensional_matching(triples; num_x=nothing, num_y=nothing, num_z=nothing, weights=nothing, target_size=nothing, optimizer=nothing)

Build a JuMP model for Karp #17 (3-Dimensional Matching). Given candidate triples (x_i, y_j, z_k), selects a pairwise disjoint subset of triples maximizing sum(weights[t] * m[t]).

source
QUBO.Karp21.knapsack — Function
Karp21.knapsack(weights, values, capacity; optimizer=nothing)

Build a JuMP model for Karp #18 (0-1 Knapsack). Maximizes sum(values[i] * x[i]) subject to sum(weights[i] * x[i]) <= capacity.

source
QUBO.Karp21.subset_sum — Function
Karp21.subset_sum(numbers, target; optimizer=nothing)

Build a JuMP model for Karp #18 (Subset Sum): sum(numbers[i] * x[i]) == target.

source
QUBO.Karp21.job_sequencing — Function
Karp21.job_sequencing(execution_times, deadlines, penalties; optimizer=nothing)

Build a JuMP model for Karp #19 (Job Sequencing). Schedules n jobs across n sequential slots via binary assignment variables x[i, k] and tardiness indicators u[i], minimizing total tardiness penalty sum(penalties[i] * u[i]).

source
QUBO.Karp21.number_partition — Function
Karp21.number_partition(numbers; exact=true, optimizer=nothing)

Build a JuMP model for Karp #20 (Partition / Number Partitioning). When exact=true (default), registers the exact partition equality constraint 2 * sum(numbers[i] * x[i]) == sum(numbers) (fixing x[1] == 1 to break symmetry). When exact=false, minimizes the squared discrepancy (sum(numbers[i] * (2x[i] - 1)))^2.

source
QUBO.Karp21.max_cut — Function
Karp21.max_cut(num_vertices, edges; weights=nothing, fix_first=true, optimizer=nothing)
Karp21.max_cut(adj_matrix; fix_first=true, optimizer=nothing)

Build a JuMP model for Karp #21 (Max-Cut). Maximizes the weighted cut value sum(w[e] * (x[u] + x[v] - 2 * x[u] * x[v])) with optional symmetry-breaking constraint x[1] == 0.
