    API

    For a complete sequence of calls, start with the user guide. This page lists individual interfaces for looking up arguments and return contracts.

    Qualified optimizer factory

    The optional solver factory is used as QUBOPreprocessing.Optimizer so that it can share a session with other solver packages. It becomes available after loading QUBODrivers.

    QUBOPreprocessing.Optimizer — Function
    QUBOPreprocessing.Optimizer(fresh_child_factory; kwargs...)

    Optional QUBODrivers/MOI optimizer factory, available after loading QUBODrivers. Use () -> QUBOPreprocessing.Optimizer(child_factory; ...) with MOI/JuMP/ToQUBO. The factory is accessed by its qualified name to avoid solver namespace collisions. It shares the sample_preprocessed implementation, snapshots the accepted compiled QUBO on each solve, restores every logical QUBO variable before source decoding, and reports the public child's proof status conservatively. A compiled optimum does not establish source-model feasibility. Core workspace use has no mandatory QUBODrivers, JuMP, ToQUBO or concrete solver dependency.

    Exported API

    QUBOPreprocessing.Checkpoint — Type
    Checkpoint

    Opaque workspace/source/branch-specific position in the conditioning trail. An ancestor remains valid after rollback; discarded descendants cannot become valid again after a new branch reaches the same depth. Reset and non-LIFO unfix invalidate checkpoints. Private fields are not a construction/mutation API.

    source
    QUBOPreprocessing.ConditionedExport — Type
    ConditionedExport

    Owned historical residual under explicit caller assumptions and/or certified deductions. status=:certified certifies exact algebra/transport within that scope, not that caller assumptions retain a global optimum. The certificate contains the ordered strong-deduction proof when present; no solver proof is produced. Original labels/maps, scope and exact residual data are immutable snapshots; export_model returns a separately owned QUBOTools model.

    source
    QUBOPreprocessing.DominanceAttempt — Type

    Proof attempt with optional certificate, stop_reason, numeric method, adjacency edge_visits, and explicit exact_fallbacks/exact_work counters.

    source
    QUBOPreprocessing.DominanceCertificate — Type
    DominanceCertificate

    Owned source/generation, explicit caller scope and ordered strict-dominance steps. Every step retains all scoped optima. This is a proof of restrictions, not a certificate that a supplied solver state is optimal. Source, scope and step capture are explicit export work; the propagation layer can retain compact DominanceStep records without copying the source at each inference.

    source
    QUBOPreprocessing.DominanceStep — Type
    DominanceStep

    Compact strong-persistency witness. Bounds enclose the normalized derivative of the unscaled objective: normalization multiplies by the sign of scale and objective sense, never by a potentially overflowing magnitude. predecessors is the number of preceding steps in the ordered certificate prefix; every preceding deduction is therefore explicit without copying the chain per step. constant binds the exact conditioned offset. Indices refer to original order.

    source
    QUBOPreprocessing.EnergyEvaluation — Type

    Ordinary Float64 energy, with finite and method; it is not an exact proof.

    source
    QUBOPreprocessing.ExportResult — Type
    ExportResult

    Owned immutable identity export, with status == :certified, original scope and an empty reduction chain. This certifies unchanged representation only. Obtain a separately owned mutable solver model with export_model. Private fields are implementation details, not a mutation API.

    source
    QUBOPreprocessing.Generation — Type
    Generation

    Opaque identity for one workspace and one accepted source snapshot. Equality matches both identities; it is neither a source hash nor an optimality proof.

    source
    QUBOPreprocessing.IdentityReport — Type

    No-inference report: :quiescent means identity completion, never solver optimality.

    source
    QUBOPreprocessing.PropagationReport — Type
    PropagationReport

    Bounded-call result with generation/checkpoint, stop_reason, examined candidates, edge_visits, new deductions, reserved exact_work, raw pending queue entries and cumulative propagation totals. Counters measure executed/reserved work and are not undone by model rollback. Caller updates, initial construction, proof export and verification remain separate boundaries.

    source
    QUBOPreprocessing.Reconstruction — Type

    Complete owned original-order state, numerical energy, and historical generation.

    source
    QUBOPreprocessing.RollbackReport — Type
    RollbackReport

    Optional owned rollback result: source generation, restored checkpoint, caller_unfixed and deduction_unfixed vectors of original-index => removed-value pairs in reverse application order. These are indices, unlike the label-based assumptions/deductions queries. They describe removals, not new proof claims.

    source
    QUBOPreprocessing.SolverResult — Type
    SolverResult

    Owned direct-consumer evidence. samples contain complete original-order reconstructions and reads their multiplicities. optimal applies only to the original scope; scope_optimal can instead certify the retained caller scope. stop_reason, public child_status, generation, captured exported residual, and metadata retain work/timing/proof/capacity information. workspace is the live workspace used for the call; captured exports/samples remain historical when that workspace changes. A timeout can retain validated samples without an optimality claim. No missing free values are invented.

    source
    QUBOPreprocessing.UpdateReport — Type
    UpdateReport

    An atomic caller update: stop_reason is :applied, :unchanged, :work_limit or :deadline. edge_visits counts adjacency entries visited, and changed counts caller assumptions added/removed. This is not an inference/proof report.

    source
    QUBOPreprocessing.VerificationResult — Type

    Read-only verification result: valid, stop_reason and charged term_visits. A budget/deadline stop is not verification success.

    source
    QUBOPreprocessing.Workspace — Type
    Workspace(model; rules=:identity)

    Privately snapshot a finite Float64 QUBOTools model and its ordered labels. :identity performs no inference; :dominance prepares exact bound caches and a deterministic queue for propagate!. Explicit caller assumptions and certified deductions have separate provenance and can be rolled back. Source edits never change the snapshot; use reset! to accept a new source. Labels must have stable equality/hash semantics and preserve equality/hash under owned deep copies. Use each workspace serially. Model metadata, solutions and warm starts are outside the objective snapshot.

    source
    QUBOPreprocessing.assume! — Method
    assume!(ws, label, value; max_work=typemax(Int), deadline_ns=nothing)

    Condition on one explicit original-label assignment, never a certified deduction. Repeat assignments are no-ops, including a matching certified deduction; they do not promote deductions into independent caller assumptions. Roll back before imposing such an independent assumption. Conflicts/invalid values throw before mutation. Reserve the variable's complete adjacency work before starting. A work/deadline stop leaves state unchanged. Preparation checks the deadline per incident edge; commit is one atomic algorithmic boundary (not asynchronous interrupt safety). An applied update costs O(degree), stores touched free fields and queues affected free neighbors once. Arithmetic uses exact rationals of the stored Float64 data; integer bit complexity and allocations are additional to edge counts.

    source
    QUBOPreprocessing.assumptions — Method
    assumptions(ws)

    Return owned original-label/value pairs in application order, O(k) for k active assumptions. No graph scan, residual construction or proof claim is involved.

    source
    QUBOPreprocessing.changes — Method
    changes(ws, checkpoint)

    Return owned caller assumptions added since a still-valid ancestor checkpoint, in application order; O(number of changes), with no full residual copy.

    source
    QUBOPreprocessing.checkpoint — Method

    checkpoint(ws) captures a constant-size position without copying the model.

    source
    QUBOPreprocessing.deductions — Method
    deductions(ws; since=nothing)

    Return owned original-label/value pairs for certified deductions, optionally added after a valid ancestor checkpoint. Scan only fixing records in that range; queue-only history and the source graph are not scanned. Caller assumptions remain available separately through assumptions/changes.

    source
    QUBOPreprocessing.export_certificate — Method
    export_certificate(ws)

    Explicitly capture the complete owned strong-deduction chain and caller scope, or return nothing in constant-size work if no deduction exists. Source/proof copying is O(n+m+number of steps), plus scalar bit/label-copy costs. Verify with verify_certificate; applicability requires the captured current trail tip. No inference, solver dispatch or residual materialization occurs here.

    source
    QUBOPreprocessing.export_model — Method
    export_model(result)

    Return a fresh QUBOTools model with exactly the captured stored objective and ordered labels. Each call owns all mutable data. Editing this model does not edit the export certificate or the historical source used by reconstruction.

    source
    QUBOPreprocessing.generation — Method

    generation(ws_or_export) returns its immutable source/workspace identity.

    source
    QUBOPreprocessing.index_map — Method

    index_map(ws_or_export) returns an owned original-index → residual-index vector.

    source
    QUBOPreprocessing.materialize — Method
    materialize(ws; coefficient_type=Float64)

    Explicitly capture an owned export. Without fixings this is the unchanged Float64 identity export. With caller assumptions or certified deductions, return a ConditionedExport with the complete proof chain when present: Float64 transport must represent every conditioned coefficient exactly, or the call raises ArgumentError; use coefficient_type=Rational{BigInt} for exact transport. Materialization scans/copies the graph; it is never implicit in updates.

    source
    QUBOPreprocessing.original_variables — Method

    original_variables(ws_or_export) returns owned labels in original index order.

    QUBOPreprocessing.preprocess — Method
    preprocess(model; rules=:identity)

    Return (workspace, report) using the same snapshot path as Workspace. :identity returns a no-inference IdentityReport; :dominance runs propagate! with forwarded keyword limits and returns its report. No model is materialized implicitly.

    QUBOPreprocessing.propagate! — Method
    propagate!(ws; max_work=typemax(Int), max_deductions=typemax(Int),
           max_exact_work=typemax(Int), deadline_ns=nothing)

    Run deterministic strict dominance on a workspace selected with rules=:dominance. Exact derivative-bound caches are prepared once and updated with touched free neighbors; a dirty candidate reads its cached bounds without rescanning its adjacency. Ties/zero scale produce no fixing. No weak or heuristic rule is enabled. Calls never build a residual or copy the source graph.

    Per-call max_work bounds examined candidates plus adjacency entries visited while installing deductions. Exact work reserves one cached sign check and, for an attempted update, one constant plus three values per incident edge; fixed-neighbor skips may make this conservative. Bit complexity is additional. Reserve complete updates before committing. A refused update leaves its queue entry pending; its charged check can be repeated on resumption. Stops retain a sound prefix with :work_limit, :deduction_limit, :verification_limit or :deadline; :quiescent means the queue is empty, not solver optimality.

    Queue consumption and deductions are trailed. Rollback restores queue/caches/ proofs; execution counters retain actual work. Initialization may scan the graph; subsequent no-change calls are constant-size. Arbitrary caller unfix conservatively rebuilds/replays explicit assumptions and discards deductions before resumption.

    source
    QUBOPreprocessing.prove_dominance — Method
    prove_dominance(ws, label; max_work=typemax(Int),
                max_exact_work=typemax(Int), deadline_ns=nothing)

    Prove one strong strict-dominance restriction without changing the workspace. Use signed derivative bounds under the current explicit caller assumptions, with conservative floating enclosures and budgeted exact fallback. Ties, zero scale, work/deadline exhaustion and unresolved signs yield no certificate. edge_visits includes both passes; fallback work/allocations remain explicit.

    The numeric check touches incident adjacency. Successful public proof export additionally copies O(n+m) source data and O(k) assumptions; it is an explicit verification/export boundary, not an inner-loop propagation API. No deduction is installed here. Select rules=:dominance and call propagate! to commit a bounded cascade using the workspace's exact caches.

    source
    QUBOPreprocessing.reconstruct — Function
    reconstruct(result, y)

    Validate a complete one-based original-domain vector and return an owned state and ordinary Float64 original-energy evaluation. Reject missing, partial, non-real, nonfinite and out-of-domain values. Numerical overflow is reported in energy.finite; neither the energy nor this reconstruction certifies optimality.

    source
    QUBOPreprocessing.reset! — Method
    reset!(ws, model)

    Validate a fresh snapshot before committing it. Failed validation preserves the old workspace. Success creates a fresh generation, including for an identical source. Owned exports remain evidence for their historical generation.

    source
    QUBOPreprocessing.rollback! — Method
    rollback!(ws, checkpoint; report=false)

    Restore fields, constant, free/fixed values, queue flags and assumptions exactly in reverse trail order. Cost is proportional to undone entries/touched fields and appended queue entries. No source graph copy or floating subtraction occurs. Invalid checkpoints fail before mutation. Rollback completes without a work or deadline limit; callers bound its cost by bounding preceding updates.

    By default return ws. With report=true, return a RollbackReport whose removed-fixing vectors are prepared before mutation. Capture visits only fixing records after cp, not queue-only history or unrelated source vertices. Rollback itself still costs all undone journal/field/queue work. Empty reports cost constant-size work and no full materialization is needed.

    source
    QUBOPreprocessing.sample_preprocessed — Function
    sample_preprocessed(model_or_workspace, fresh_child_factory; kwargs...)

    Optional direct consumer, available after loading QUBODrivers 0.6.5 or later. Use an existing workspace or construct one with rules=:dominance (the model default) / :identity. Explicitly capture a Float64-safe residual, verify its proof chain, invoke a fresh Float64 QUBODrivers child, validate complete states, and recompute original energies with one shared source evaluator per call. All-fixed cases run locally. Return a SolverResult.

    Supported keywords include max_work, max_deductions, max_exact_work, absolute deadline_ns, max_child_variables=16, max_results=1024 and child_work_bound=nothing. Work is one shared allowance for charged adapter storage/update/verification/reconstruction units and a reserved child bound. The built-in ExactSampler has a conservative bound; another finite-work child requires a supplied (child, residual, remaining_work, deadline_ns) -> nonnegative Int bound that the child honors, otherwise dispatch abstains. Deadline checks surround noninterruptible copy boundaries; remaining seconds are passed through MOI.TimeLimitSec when supported. A child is responsible for honoring its declared bounds/deadline. There is no hard real-time/process-preemption guarantee.

    Unsafe Float64 transport abstains before child dispatch. Exact residuals remain available through the core materialization API. Valid heuristic/interrupted child states do not gain optimality from certified preprocessing. The child's public MOI.OPTIMAL is retained only for a verified complete chain, validated result1, finite original energy and unexpired allowance. Caller scopes remain qualified. Sampling distributions and physical-read semantics are not preserved.

    source
    QUBOPreprocessing.unfix! — Method
    unfix!(ws, label; max_work=typemax(Int), deadline_ns=nothing)

    Remove a caller assumption. The most recent one rolls back locally. Otherwise build fresh algebra and replay all retained assumptions, then replace state only on success; every prior checkpoint is invalidated. This conservative path costs O(n+m + retained adjacency work), plus exact arithmetic, and allocates a new workspace state. max_work bounds replay adjacency visits, not initialization; the latter always costs O(n+m). Deadline/work stops preserve the old state. Later deductions are undone by the local path. Non-LIFO replay discards all deductions and replays only explicit caller assumptions, never inferred values. Resume inference explicitly with propagate!. Removing a deduction directly is rejected; use its ancestor checkpoint.

    source
    QUBOPreprocessing.verify_certificate — Method
    verify_certificate(ws, certificate; max_work=typemax(Int), deadline_ns=nothing)

    Independently recheck source identity, current caller scope and the complete ordered strong-dominance chain using exact original-coefficient substitution. Never trust cached workspace fields or an authenticated identifier alone. Undoing/changing assumptions or resetting the model invalidates applicability. Source/label validation costs O(n+m); each step scans source storage, so this explicit verifier can cost O(steps*(n+m)). Dense storage costs O(n²) per scan. Work is reserved before scans; exhausted work/deadline yields valid=false. This does not validate a solver optimum or certify a rounded residual export.
