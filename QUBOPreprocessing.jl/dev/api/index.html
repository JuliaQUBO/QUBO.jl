    API

    For a complete sequence of calls, start with the user guide. This page lists individual interfaces for looking up arguments and return contracts.

    Qualified optimizer factory

    The optional solver factory is used as QUBOPreprocessing.Optimizer so that it can share a session with other solver packages. It becomes available after loading QUBODrivers.

    QUBOPreprocessing.Optimizer — Function
    QUBOPreprocessing.Optimizer(fresh_child_factory; kwargs...)

    Optional QUBODrivers/MOI optimizer factory, available after loading QUBODrivers. Use () -> QUBOPreprocessing.Optimizer(child_factory; ...) with MOI/JuMP/ToQUBO. The factory is accessed by its qualified name to avoid solver namespace collisions. It shares the sample_preprocessed implementation, snapshots the accepted compiled QUBO on each solve, restores every logical QUBO variable before source decoding, and reports the public child's proof status conservatively. A compiled optimum does not establish source-model feasibility. Core workspace use has no mandatory QUBODrivers, JuMP, ToQUBO or concrete solver dependency.

    QUBOPreprocessing.CompressionAuditReport — Type
    CompressionAuditReport{V}

    Bounded exact audit report comparing an original model $F$ against a coefficient-compressed or sparsified model $F'$ under QUBOPreprocessing.jl's residual-to-original guarantee $\operatorname{lift}(\operatorname{opt}(F')) \subseteq \operatorname{opt}(F)$.

    Fields:

    • stop_reason::Symbol: :audited, :variable_limit_exceeded, or :work_limit_exceeded
    • relation::Symbol:
      • :exact_optimum_set ($\operatorname{opt}(F') = \operatorname{opt}(F)$)
      • :optimum_preserving_subset ($\emptyset \ne \operatorname{opt}(F') \subsetneq \operatorname{opt}(F)$)
      • :introduced_suboptimal_tie ($\operatorname{opt}(F) \subsetneq \operatorname{opt}(F')$; violates residual-to-original reconstruction because $\operatorname{opt}(F') \setminus \operatorname{opt}(F) \ne \emptyset$)
      • :partial_overlap_with_suboptimal ($\operatorname{opt}(F) \cap \operatorname{opt}(F') \ne \emptyset$, but neither set contains the other; violates residual-to-original reconstruction)
      • :disjoint_optimum_sets ($\operatorname{opt}(F) \cap \operatorname{opt}(F') = \emptyset$; all original global optima are lost)
      • :unverified (audit budget or variable cap exceeded before exhaustive check)
    • residual_to_original_valid::Bool: true iff stop_reason === :audited and every optimal state of $F'$ is also globally optimal in $F$ ($\emptyset \ne \operatorname{opt}(F') \subseteq \operatorname{opt}(F)$)
    • constant_energy_shift::Bool: true iff $F(x) - F'(x)$ is constant across all $2^n$ feasible states
    • optimal_energy_shift::Union{Nothing,Rational{BigInt}}: exact shift $F(x^*) - F'(x^*)$ when constant across $x^* \in \operatorname{opt}(F')$, else nothing
    • valid_lower_bound_shift::Rational{BigInt}: exact worst-case bound shift $\min_{x} (F(x) - F'(x))$ on normalized minimization energy
    • original_optimal_value::Rational{BigInt}: exact optimal objective value of $F$ (in user sense/scale/offset)
    • transformed_optimal_value::Rational{BigInt}: exact optimal objective value of $F'$ (in user sense/scale/offset)
    • worst_lifted_original_value::Rational{BigInt}: worst original objective value $F(x')$ among $x' \in \operatorname{opt}(F')$
    • original_optima_count::Int, transformed_optima_count::Int, shared_optima_count::Int
    • introduced_suboptimal_witness::Union{Nothing,Vector{Int}}: state $x' \in \operatorname{opt}(F') \setminus \operatorname{opt}(F)$ if any
    • lost_optimum_witness::Union{Nothing,Vector{Int}}: state $x^* \in \operatorname{opt}(F) \setminus \operatorname{opt}(F')$ if any
    • subsumed_by_dominance::Bool: whether all sound candidates in this transformation are already subsumed by exact unary fixing (#14) or pair contraction (#15)
    • subsuming_rule::Symbol: :none, :zero_noop, :unary_dominance, or :pair_dominance
    • decision::Symbol: :defer, :adopt_via_exact_elimination, or :noop
    • missing_proof::Symbol: explicit mathematical reason why in-place coefficient compression is deferred
    • candidates::Vector{CompressionCandidate{V}}
    • metrics::CompressionMetrics
    • states_evaluated::Int, bound_work::Int, verification_work::Int, reconstruction_work::Int, total_work::Int

    QUBOPreprocessing.CompressionCandidate — Type
    CompressionCandidate{V}

    Bounded local coefficient-compression candidate audited under Issue #21 (Mücke, Gerlach & Piatkowski 2023, Optimum-Preserving QUBO Parameter Compression, Definition 3 and Theorem 2, arXiv:2307.02195; audited against qubolitereduce_dynamic_range at commit cbe57e0bea68e9f751f8591e3ba0254030ac5965).

    Fields:

    • kind::Symbol: :linear (diagonal $L_i \mapsto L_i'$) or :quadratic (off-diagonal $Q_{ij} \mapsto Q_{ij}'$)
    • variables::Tuple{V,Union{Nothing,V}}: (u, nothing) for :linear, (u, v) for :quadratic
    • indices::Tuple{Int,Int}: (i, 0) for :linear, (i, j) (i < j) for :quadratic
    • rule::Symbol: :qubolite_linear_closed, :qubolite_linear_open, :qubolite_quadratic_pos_closed, :qubolite_quadratic_pos_open, :qubolite_quadratic_neg_closed, :qubolite_quadratic_neg_open, or :custom
    • endpoint::Symbol: :closed (\epsilon = 0) or :open (\epsilon > 0)
    • original_coeff::Rational{BigInt}: exact normalized Boolean minimization coefficient before update
    • compressed_coeff::Rational{BigInt}: exact normalized Boolean minimization coefficient after update
    • delta::Rational{BigInt}: compressed_coeff - original_coeff
    • lower_bound::Rational{BigInt}: local 1-hop derivative lower bound (c_i^- or c_{a,-b}^-)
    • upper_bound::Rational{BigInt}: local 1-hop derivative upper bound (c_i^+ or c_{a,-b}^+)
    • strict_local_dominance::Bool: whether strict 1-hop local dominance (L_i + c_i^- > 0, L_i + c_i^+ < 0, or pair implication x_i x_j = 0) already holds in the original model
    • subsuming_rule::Symbol: :none, :unary_dominance (#14), or :pair_dominance (#15)

    QUBOPreprocessing.DomainGaugeMap — Type
    DomainGaugeMap

    Checked coordinate bijection between a workspace's accepted source model and a target domain (:bool or :spin) with spin gauge $s_i = g_i t_i$ where $g_i \in \{-1, +1\}$. For binary coordinates $x_i \in \{0, 1\}$ and canonical spin coordinates $s_i = 2x_i - 1 \in \{-1, +1\}$, the unscaled polynomial satisfies $J_{ij} = b_{ij}/4$, $h_i = a_i/2 + \sum_{j \ne i} b_{ij}/4$ and $c_{\text{spin}} = c_{\text{bool}} + \frac{1}{2}\sum_i a_i + \frac{1}{4}\sum_{i<j} b_{ij}$. Under gauge $g_i$, spin fields transform as $h'_i = g_i h_i$ and couplings as $J'_{ij} = g_i g_j J_{ij}$ with unchanged spin constant. Target binary coordinates relate to gauged spins by $t_i = 2u_i - 1$.

    Retains generation, source_domain, target_domain, sense, scale, offset, gauge and ordered source identity. This is a bijective coordinate map, not a variable fixing, local elimination or symmetry-breaking selection; optional gauge selection transforms fields rather than assuming zero fields.

    QUBOPreprocessing.MaxCutGraph — Type
    MaxCutGraph{V}

    Exact signed weighted Max-Cut representation of the active direction-normalized Ising residual of a Workspace:

    \[\tilde{F}(t) = \tilde{c}_{\text{spin}} + \sum_{u \in F} \tilde{h}_u t_u + \sum_{u < v \in F} \tilde{J}_{uv} t_u t_v = C_{\text{cut}} - \sum_{(a, b) \in E_{\text{cut}}} w_{ab} \, \delta(z_a \ne z_b),\]

    where reference_vertex == 0 carries spin $z_0 \in \{-1, +1\}$, each active variable $u \in F$ carries cut spin $z_u \in \{-1, +1\}$ related to gauged spin $t_u = z_0 z_u$ (and original canonical spin $s_u = g_u z_0 z_u$), reference edges have weight $w_{0,u} = 2\tilde{h}_u$, internal edges have weight $w_{uv} = 2\tilde{J}_{uv}$, and $C_{\text{cut}} = \tilde{c}_{\text{spin}} + \sum_{u \in F} \tilde{h}_u + \sum_{u < v \in F} \tilde{J}_{uv}$.

    Global cut reversal $z \mapsto -z$ preserves both $\operatorname{CutWeight}(z)$ and every physical spin $s_u = g_u z_0 z_u$.

    QUBOPreprocessing.Workspace — Type
    Workspace(model; rules=:identity, integerize_scale::Bool=false, max_decimals::Integer=9, atol::Real=0.0)

    Privately snapshot a finite Float64 QUBOTools model and its ordered labels. :identity performs no inference; :dominance prepares exact bound caches and a deterministic queue for propagate!. When integerize_scale=true, the snapshot searches $0 \le a, b \le \min(\text{max\_decimals}, 300)$ for the smallest common denominator $m = 2^a \cdot 5^b$ to factor into scale(model) / m via integerize_scale before building exact integer state. With the default atol=0.0, this rescaling is exact (Rational{BigInt}(v) * m must be an integer for every coefficient and offset and Rational{BigInt}(scale(model) / m) * m == Rational{BigInt}(scale(model)), with no rounding); passing atol > 0 opts in to tolerance-based decimal rounding.

    QUBOPreprocessing.schedule_budgeted! — Method
    schedule_budgeted!(ws; time_limit, allow_weak=false, enable_probing=true,
                   max_block_size=12, probe_rounds=8, guaranteed_relation_work=75_000,
                   tie_break=:low, double_probe=false, contract_relations=false,
                   on_family=nothing)

    Run every certified reduction family on ws under one wall-clock budget of time_limit seconds, instead of caller-chosen size gates. The budget counts from this call; building ws (snapshot import and integerization) happens before it starts.

    The cheap rules (dominance, low-degree and star-triangle elimination, pair relations: schedule_reductions!) first reach a fixpoint whatever the budget, with pair-relation search limited to guaranteed_relation_work work units. So a small budget never does less than this floor, while relation search cannot run for minutes on a dense model. time_limit is therefore a soft cutoff: the floor can run past it. Within the budget, the cheap rules continue without the relation limit, and the expensive families run in turn — roof duality, submodular cuts, Max-Cut, block elimination (max_block_size), residual-SCC contraction and, when enable_probing, coercive-order probing with probe_rounds trial rounds. Each of these gets an equal share of the budget still left, so one slow family cannot consume it all and time a fast family leaves passes to the next. The cheap rules run again, with the next family's share, after every expensive family that removes a variable. Passes repeat while some family has not finished on the current workspace: a family runs again when its share ran out before it finished, or when variables were removed after its last run. Every budgeted call shares the deadline, so the schedule returns within a small margin of time_limit or of the end of the cheap floor, whichever is later, and an interrupted call rolls back cleanly. On large dense models, garbage collection of exact-arithmetic temporaries can still stretch a call past its share.

    allow_weak=true additionally applies weak dominance, weak relations and weak submodular/Max-Cut reductions, which keep at least one optimum; exact elimination may resolve ties in either mode. Returns a BudgetedScheduleReport with per-family time and removed variables.

    double_probe and contract_relations opt into the corresponding probing operations; both default to false, preserving the original budgeted policy. An optional on_family(event) function observes every completed family call. The event includes family, time_s, freed, stop_reason, and public before_checkpoint/after_checkpoint values. Callback time consumes the shared scheduling budget but is excluded from the family's own time. Callback exceptions propagate; already completed deductions are not rolled back. The callback must not mutate the workspace. The default performs no callback/checkpoint work.
