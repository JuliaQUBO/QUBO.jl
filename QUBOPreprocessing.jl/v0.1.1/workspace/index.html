    Reversible conditioning

    Use a workspace directly when a search or neighborhood method revisits the same model under different assumptions. The branch walkthrough shows the complete loop; this reference explains what each update captures and which costs you need to budget.

    The workspace prepares signed sparse adjacency once and stores exact rational boundary fields and constants for both binary and spin coordinates, plus per-variable free interaction degrees (degree(ws, label)). Stored zero quadratic entries do not inflate degrees, and linear fields (effective_field(ws, label; map=...)) are tracked separately from remaining nonzero interactions (incident_couplings(ws, label; map=...)). It retains the original domain, sense, scale and label order; no full QUBO–Ising casts occur during updates. Dense input is read once during initialization. rules=:identity has no inference; dominance separately records inferred values.

    using QUBOPreprocessing
import QUBOTools as QT
ws = Workspace(QT.Model(Dict(:x=>1.0,:y=>-2.0),Dict((:x,:y)=>0.5)))
root = checkpoint(ws)
assume!(ws,:x,1; max_work=1)
changes(ws,root)

 :x => 1
    result = materialize(ws)
residual = export_model(result)
restored = reconstruct(result,[1])
@assert restored.energy.value == -0.5
rollback!(ws,root)
@assert isempty(assumptions(ws))
restored.state

    assume! takes an original label, including when labels are integers; it does not take a compact residual index. Duplicate assignments are no-ops and conflicts or invalid values fail before mutation. A duplicate of an inferred value is also a no-op and does not create an independent caller premise. Roll back before imposing such a premise. Caller assumptions only describe a restricted problem. A residual optimum lifts to an optimum within that scope, which need not contain any original global optimum. The residual export has certificate.scope == :assumptions; an empty reduction chain makes no inference claim when only callers are present. With deductions, a separate ordered strong proof is included. Source fields/scale/offset are exact binary values of the accepted finite Float64 input. Conditioning uses Rational{BigInt} internally to prevent cancellation drift and overflow in reversible algebra. This is algebraic storage; inference additionally records independently verifiable proof evidence.

    checkpoint is constant-size. Nested rollback! restores prior fields, constant, fixed flags, pending dirty queue and assumption provenance exactly. Discarded future checkpoints are rejected even if a later branch reaches the same depth. Other workspaces and new reset! generations cannot reuse them. Original model edits never alter a workspace; accept coefficient/penalty changes through transactional reset!, which rebuilds state and changes generation. Historical exports keep their original objective and scope.

    unfix! on the most recent assumption uses local rollback. Removing an older assumption conservatively builds fresh state and replays retained assumptions in their application order. Replacement happens only on success and invalidates all old checkpoints. It costs O(n+m + total retained adjacency visits), plus exact arithmetic, and allocates a fresh state. It is not a local-cost promise. Non-LIFO replay discards all deductions, retains only explicit caller pins, and creates a fresh checkpoint epoch. The caller resumes propagation explicitly. Local unfix removes the last caller and deductions after it; earlier proofs remain valid. unfix! rejects inferred variables; roll back before their deduction.

    Work, allocation and interruption boundaries

    Sparse initialization costs O(n+m) structural work/storage; raw dense input costs O(n²) to read/copy. Each assumption visits its source degree (including already fixed neighbors), updates only free neighbors, and appends compact undo records and dirty queue entries. Each affected neighbor is queued at most once; propagation consumes and trails the queue cursor. Rollback costs undone field/trail/queue work, without a graph scan or floating subtraction. Mutable state is private to each serial workspace. Exact integer bit complexity, allocations and label hash/copy costs are additional to structural counts.

    max_work is a nonnegative integer adjacency-visit budget for an update. deadline_ns is an absolute UInt64 monotonic time_ns() deadline. An update reserves all incident work, prepares changes separately, checks deadlines during preparation, then commits at one algorithmic boundary. :work_limit and :deadline return without mutation; allocation failures during preparation likewise leave state unchanged. Rollback and the short commit phase complete without deadline interruption. Asynchronous process interrupts and out-of-memory termination are not transactional cancellation mechanisms. Non-LIFO unfix charges replay adjacency visits to max_work; initialization still costs O(n+m), and deadline checks surround rather than interrupt initialization.

    changes(ws, cp) and assumptions(ws) allocate owned pairs proportional to the fixing records in the requested range, without scanning the graph or queue-only history. deductions(ws; since=cp) separately returns inferred pairs. No-change changes and duplicate assumptions avoid graph traversal. index_map explicitly scans n original positions, returning zero for fixed variables and compact positive indices for free variables. The source's original label order is preserved.

    materialize and export_model are explicit O(n+m) boundaries. With no fixings the original bit-preserving identity export is retained. Under caller or inferred fixings, default Float64 export requires every transformed coefficient and constant to be exactly representable, otherwise it raises ArgumentError. Use materialize(ws; coefficient_type=Rational{BigInt}) for the exact residual; a solver must explicitly support that type. This conservative rule does not silently round, rescale or claim a heuristic fallback is certified. Original reconstruction still reports ordinary Float64 energy with a finite flag, not an exact energy or proof that the supplied solution is optimal.

    Future elimination/contraction passes can change graph topology. Their extension point is the internal trail in src/trail.jl: they must add trailed topology and reconstruction records before modifying adjacency. This slice deliberately trails only conditioning and does not pretend to implement those later passes.

    Run examples/workspace.jl and scripts/workspace_costs.jl for usage and bounded warm measurements. Structural/allocation tests guard local work independently of wall time. Measured end-to-end adoption and the accepted operating envelope remain with QUBOBenchmarks issue #30; a reduced variable count is not evidence that preprocessing pays off.

    Use rollback!(ws, cp; report=true) for owned original-index/value removal reports separated by caller/deduction provenance. See branch workloads for its query costs, bounded branch search and replay stress tests.
